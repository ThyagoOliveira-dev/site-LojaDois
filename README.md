🛍️ Loja Dois - Sistema de Gerenciamento
Sistema desenvolvido para gerenciamento de produtos e autenticação de usuários, simulando o backend de uma loja real.

🚀 Funcionalidades: Autenticação de usuários (login) | Cadastro de usuários | Cadastro de produtos | Listagem de produtos | Busca de produtos | Proteção de rotas com autenticação
| API REST estruturada

🧠 Objetivo do projeto: 
Este projeto foi desenvolvido com foco em aprendizado prático de backend utilizando Java, simulando um sistema real com regras de negócio, autenticação e persistência de dados.

🛠️ Tecnologias utilizadas:
| Java
| Spring Boot
| Spring Security
| Maven
| Banco de dados: H2 (por enquanto)
| JPA / Hibernate

🔗 Endpoints principais:
🔐 Autenticação
| POST /auth/login
| POST /auth/register

📦 Produtos
| GET /produtos
| POST /produtos
| GET /produtos/{id}
